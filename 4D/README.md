# 4D Track

## Purpose
This track is dedicated to general 4D-related papers for the HiLite-4D project.

## Relevant Topics
Papers relevant to this survey track include:
- Modeling 4D dynamic scenes
- General representations for spatio-temporal data
- Dynamic NeRFs and 4D Gaussian Splatting (general techniques)
- Applications in AR/VR, digital twins, telepresence, and robotics
