# Pruning Efficiency Track

## Purpose
This track focuses on papers aimed at reducing compute requirements, which is essential for enabling practical usage of 4D assets on low-compute devices (e.g., real-time rendering, fast optimization) for the HiLite-4D project.

## Relevant Topics
Papers relevant to this survey track include:
- Pruning techniques (e.g., pruning the number of Gaussians)
- Methods for improving computational efficiency and reducing memory footprint of 3D/4D reconstruction techniques.
- Different representations of motion to save computation. This can include papers that propose better deformation fields, hybrid representations that combine explicit and implicit models, etc.
- Other efficiency-focused optimizations for 3D/4D scene reconstruction
